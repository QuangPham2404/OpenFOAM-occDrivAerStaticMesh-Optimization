# builds/source

Application source tree for SPUMA `0.2-v2412` (OpenFOAM-v2412 fork).

The source is cloned on the cluster login node using:

```bash
git clone --branch 0.2-v2412 --recursive \
    https://gitlab-hpc.cineca.it/exafoam/spuma.git SPUMA-0.2-v2412
```

This directory is the designated local mirror/record location if a local copy
of the source is ever required. Source is not committed to this workflow repo
unless project policy permits.
