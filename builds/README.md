# builds

Application source, build scripts, and build evidence.

- `source/` — application source (SPUMA) cloned/copied for building.
- `build-scripts/` — one directory per build variant (`README.md`, PBS build
  script, build `.sh`, and `outputs/`). See the build directory contract in
  `workflow/02-Repo-Structure.md`.
- `extra-packages/` — explicitly approved local dependencies (currently none).
